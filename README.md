### Hi, I'm Fabian 👋

I'm an engineer who likes to understand systems all the way down.
I design boards in KiCad, write firmware for small microcontrollers, put neural nets on FPGAs,
and build ML models, data pipelines and the infrastructure to run them.
My favourite problems sit where hardware, data and software meet.

<sub>Co-founder at NexPatch AI · based in Leipzig/Erfurt, Germany</sub>

## 🌟 Featured projects

### Hardware

| Project | What it is | Stack |
|---|---|---|
| [PerceptronOnFPGA](https://github.com/Franzelfx/PerceptronOnFPGA) | Fully combinational, runtime-programmable 16×16 binary MLP: no multipliers, no clock inside the network, every perceptron is a mask, a popcount and a comparator. Runs on an Intel Cyclone 10 LP (Arduino MKR Vidor 4000). | VHDL · ModelSim |
| [AVRCubeRev2](https://github.com/Franzelfx/AVRCubeRev2) | Coin-cell electronic dice and two-axis spirit level on an ATtiny24: seven LEDs, an accelerometer, and a bit-banged I²C bus sharing pins with the ISP header. Designed as a 25-part soldering kit. | C++ · AVR · KiCad |

### ML & Systems

| Project | What it is | Stack |
|---|---|---|
| [swarmpipe](https://github.com/Franzelfx/swarmpipe) | Pipeline-parallel model execution across a few ordinary machines with different GPUs, no cluster manager required. *Pre-alpha.* | Python · PyTorch |
| [nescio](https://github.com/Franzelfx/nescio) | Calibrated abstention for self-hosted LLMs: a hidden-state probe plus conformal calibration, so a local model can say "I don't know" with a coverage guarantee. *Design phase.* | Python |
